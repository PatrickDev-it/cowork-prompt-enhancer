# Support policy

This is a portfolio reference implementation, not a hosted service. The latest stable release is
supported on Windows 11 and current Ubuntu LTS for the offline mock profile. Local GPU inference is
best-effort on the artifact versions listed in [`THIRD_PARTY.md`](THIRD_PARTY.md).

Use GitHub issues for reproducible defects and documentation gaps. Use GitHub Discussions for design or
usage questions when enabled. Security reports must follow [`SECURITY.md`](SECURITY.md). No response-time
or backward-compatibility SLA is offered before a public 1.x release.
