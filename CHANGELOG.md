## [1.0.0] - 2026-07-22

### Added

- Deterministic offline mock, supervised local llama-server and vendor-neutral OpenAI-compatible profiles.
- Versioned WebSocket protocol, bounded scheduling, cancellation, reconnect deduplication and correlation.
- Short-lived HMAC authentication for explicit non-loopback operation and canonical file confinement.
- Sixty-four-case deterministic evaluation with mock and stratified real-local reference evidence.
- Bounded opt-in request tracing across queue, compression, provider, fallback and artifact delivery.
- Reproducible setup, preflight, demo, dependency audits, secret scan, SBOM and release validation.

### Security

- Loopback-only defaults, stable public errors, frame/payload bounds and no credential logging.
- Secret and heavyweight runtime artifacts are excluded from source and validated before release.
